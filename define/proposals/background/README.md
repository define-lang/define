# Background Research

These are research notes that back the
[Define Language Proposals](../00000-language-proposals.md). They record what we
learned while designing a proposal, like surveys of other languages and the
reasoning behind a design.

They are not normative. The proposals and the
[language specification](../../spec/spec.md) say what Define is. If a note here
disagrees with a proposal or the spec, the proposal or the spec is right.

These notes are largely written by an AI, with some light review by a human.
